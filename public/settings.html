Workspaces

A workspace is a named Slack token — one for work, one for a client, as many as you need. Pick which one is active on the converter page.

Tokens live in this browser tab’s memory. Close the tab and they are gone: nothing is written to disk, nothing syncs, and the server keeps no copy.

How do I get a Slack token?
  1. At api.slack.com/apps, create a new app from scratch.
  2. Under OAuth & Permissions, add these user token scopes: channels:history, groups:history, im:history, mpim:history, users:read, files:read.
  3. Install the app to your workspace.
  4. Copy the user OAuth token — it starts with xoxp-.
