How do I get one?
  1. At api.slack.com/apps, create an app from scratch.
  2. Add these user token scopes: channels:history, groups:history, im:history, mpim:history, users:read, files:read.
  3. Install it to your workspace, then copy the xoxp- user OAuth token.
